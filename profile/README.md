## Overview

**CC Switch download** provides a desktop control center for AI coding tools on Windows and PC. Instead of managing provider settings separately across different applications, CC Switch brings supported AI coding tools, providers, routing, MCP, Skills, sessions, and usage information into one workspace.

CC Switch is designed for developers who regularly work with tools such as Claude Code, Codex, Gemini CLI, OpenCode, OpenClaw, and other supported AI coding applications. The desktop interface makes it easier to organize configurations, switch between providers, monitor usage, and maintain a consistent development setup.

The application runs natively on Windows and is also available for macOS and Linux. Windows users can choose between an MSI installer and a portable build, while Windows on ARM devices can use the ARM64 packages.
